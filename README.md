# Plop

A daily word ladder. Start from the day's four-letter word and change one letter at a time,
through real words, until you spell **POOP**. Fewer guesses is better. Share the emoji grid with
friends and compare against the shortest possible ladder.

Inspired by [Poople](https://poople.io/). This is an independent clone built for fun.

## Rules

- Each guess changes exactly one letter, in place. No rearranging.
- Every guess must be in the word list.
- A tile turns brown when its letter is correct for POOP. Changing a brown letter is allowed.
- A word can't be reused within a game.
- No guess limit. You can give up, which reveals an optimal ladder and ends your streak.
- One puzzle per day, rolling over at midnight UTC so everyone shares the same puzzle number.

## Development

```sh
npm install
npm run dev        # local dev server
npm test           # vitest
npm run typecheck
npm run build      # dist/
```

### Word lists

`src/data/words.json` is generated by `npm run words` (`scripts/build-words.mjs`) and committed:

- **Accepted moves**: every 4-letter word in [ENABLE1](https://github.com/dolph/dictionary)
  (public domain), minus the [LDNOOBW](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words)
  blocklist and anything in `scripts/exclude.txt`.
- **Daily start words**: accepted words that also appear in the
  [Google 10,000 common words](https://github.com/first20hours/google-10000-english) list, with a
  shortest ladder to POOP of 4 to 7 moves and no letter already in place, in a fixed shuffled order.

Puzzle #1 is 2026-09-24 (UTC). The schedule wraps when the pool runs out. Regenerating the list
changes future puzzles, so treat `words.json` as append-only in spirit.

If the script can't download sources (some networks block Node's fetch), drop the three files
into `scripts/.cache/` as `enable1.txt`, `common.txt`, and `blocklist.txt` and rerun.

## Deployment

GitHub Actions builds on every push and deploys `main` to GitHub Pages. Enable Pages once in the
repo settings with **Source: GitHub Actions**. The share URL is hardcoded in `src/game/share.ts`.

Stats and today's game live in `localStorage`. There is no backend.
